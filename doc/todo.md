__目标__：给 cllama 的技能/工具补上「可控制、可追溯、可升级」。动手前先读仓库的 `AGENTS.md` 了解结构。

__要求做到：__

1. 有副作用的动作（写用户数据、改页面、调外部服务）必须经用户确认才执行；拿不到确认就不执行。
2. 危险性由动作自身定义；技能只能收紧（白名单、禁用），不能放宽。
3. __审计__：每次技能执行留下轨迹——调了哪些动作、耗时、成败、断在哪一步——用户能查看；失败要显式呈现，不许被模型一句话带过。只记元数据，不记页面正文与密钥；随结果保留、可清除。
4. 内置技能与用户技能分开：升级新增的内置技能能到用户手里，用户删掉的不复活，用户改过的不被覆盖。技能带版本号，结构变更走幂等迁移，老数据能直接打开、可回退。
5. 动作能知道自己在哪个页面/会话/哪个模型上工作（不再各自去猜当前标签页）；单次调用或单个技能可指定模型，不必改全局设置。
6. 结果可继续操作（复制、继续讨论、加工、填回页面），失败可重试。

__不许破坏：__

- 技能现有的语义与易用性：自动选择/固定/关闭三态、`/` 与行内命令、选中预填、默认技能开箱可用。
- MCP 接入，以及"模型产出 → 用户确认 → 导入"这条可靠路径。
- 现有构建（Chrome / Firefox / Android）与多语言覆盖。
